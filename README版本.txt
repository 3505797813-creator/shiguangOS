拾光安装程序 v0.9.2 —— 把系统装进硬盘

这个包做什么？
把 ISO 里的系统镜像原样写到一块硬盘上，写完就能脱离 U 盘/光盘从硬盘启动。

怎么用（三选一）
1) VMware / 真机：把 拾光安装盘-v0.9.2.iso 当光盘/ISO 启动，进安装界面
2) U 盘：用 Ventoy 把这个 ISO 直接拖进 U 盘，开机选它
3) 直接改 ISO 挂载列表也行，Ventoy 支持

安装步骤
1. 开机进入「拾光安装程序」
2. 界面列出所有能装的磁盘，写的是 DISK 0 / DISK 1 和容量
3. 选中目标磁盘 → 按回车 → 出现红字警告「将抹掉整块磁盘上的全部数据」
4. 再按回车 = 真开始写，进度条走完显示「安装完成」
5. 按回车重启，开机前把 U 盘/ISO 摘掉（或者进 BIOS 把硬盘设第一启动项）

必须知道的三件事
- 这是整盘覆盖，选错盘那块盘的数据就没了，所以界面故意要你按两次回车
- 只列大于 64MB 的可写磁盘，光盘和只读设备不会出现在列表里
- 装完程序会往 UEFI 里登记一个「Shiguang OS」启动项并排进启动顺序；部分主板仍要手动选一次硬盘

当前限制（还没做的）
- 只做原样克隆，装完硬盘上大部分空间是未分配的（镜像只有 64MB）
- 还没有 GPT 重写，MBR+FAT16 的老主板可能不认；新主板多数能吃
